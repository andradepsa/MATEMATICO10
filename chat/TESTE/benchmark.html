📖 Definitive Manual: K10 Hydra Developer Suite

This tool is an Isolated Test Harness. It allows auditors and developers to attack, verify, and simulate real WebRTC connections within the K10 Chat architecture, without needing to "dirty" the production code with visible test buttons for regular users.

🏝️ Tab 1: War-Room (Islands & PEX)

Objective: Simulate the organic behavior of the network when partitioned (several "islands" of users operating in isolation and then connecting).

  • Spawn Population: Creates 25 simulated bots acting safely. They emit directory-announce packets and create a healthy topological network.
  • PEX Bridge (Group Merge): Represents the moment Island A "discovers" Island B. Pasting the K10 ID of another computer makes the bots eject the local topology into the remote network. This verifies the vital Idempotency rule (Math.max) of the original K10 — validating if the code safely accepts the new population without an infinite inflation loop.

💀 Tab 2: Attack & Stress

Objective: Test the browser's resilience and the raw defenses of the target code (Bandwidth and Memory/OOM Limits).

  • 🌊 Tsunami (Cache LRU): Dumps violent, asynchronous bursts of messages (thousands per second). The goal is to cause a RAM memory leak in the target browser. If Chat K10 doesn't crash, it means the LRU hard-cap filter (limit of 10,000 hash table records) worked perfectly.
  • 🌍 Topology DDoS: Spoofs a PEX protocol warning Chat K10 that there are 1850 nodes disputing the election, forcing a destructive group-split command. Tests if the slice(0, 10) and the server group size locks can keep the tree stable.
  • 💀 Inject 2GB File (Poison): Exploits buffer fragility (Uint8Array). Sends radio-start packets requesting the allocation of 2 Billion Bytes followed by absurd offsets. If the K10 tab remains alive, the "Bounds Check" (Limits lock < 256KB) operated seamlessly.

🔬 Tab 3: V8 Static Audit

Objective: Perform a "Mapped Ray-X" directly on non-executed code to prevent behavioral regressions.

Instead of scanning external network behavior, this tab reads the lines of code from the source file (chat.html or server.html) using advanced Regular Expressions (Strict Regex).

  • Ensures no defensive line accidentally vanished during human editing or refactoring (like the React isDuplicate).
  • Blocks deployments lacking the formal URL.revokeObjectURL() release, preventing zombie memory retention (Audio Blob Limits).

⚠️ Tips & Troubleshooting

  • "Tracking Prevention blocked access": When executed locally via "File://", Chrome or Edge will block cloud trackers (PeerJS Proxy) if many tabs ping simultaneously. Ignore the red "Storage" warnings in the console (F12). They do not break the peer-to-peer WebRTC of the tool.
  • "Frozen" Tabs: For the Island War test to validate on the same computer, place Chat A and Chat B in separate visible screens (side-by-side). If a tab is hidden or docked, Chrome's performance engine suspends WebSockets, causing delays in attacks/PEX merges.
