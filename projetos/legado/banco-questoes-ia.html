IA Geradora de Questões (Cadeia de Markov)

Uma IA simples que roda 100% na memória do navegador. Ela aprende os padrões dos textos dos datasets usando cadeia de Markov de ordem N, gera novas questões sobre qualquer tópico e o modelo é serializado em base64 no localStorage — pode ser exportado, importado e reutilizado.

1. Treinar a IA

Escolha um tópico para a IA aprender. Ela vai buscar datasets relevantes e treinar a cadeia de Markov com os textos.

2. Modelo em Base64

O modelo treinado fica salvo aqui e no localStorage. Você pode copiar, exportar e importar.

3. Gerar Questões

A IA combina a cadeia de Markov (aprendeu padrões) com templates estruturais para gerar questões. Cada questão vem com a resposta certa baseada nos dados reais.

Como a IA funciona (sem rede neural)

Esta "IA" é uma cadeia de Markov — um modelo estatístico clássico (1906!) muito antes do deep learning. A IA aprende qual palavra costuma vir depois de cada sequência de N palavras vistas. Para gerar texto, ela começa com uma semente e "caminha" probabilisticamente pelo que aprendeu. É o mesmo princípio do autocomplete do celular, mas mais sofisticado. Não precisa de GPU, internet ou servidor — roda em puro JavaScript na memória do navegador.

  • Tokenização: divide os textos em palavras (lowercase, sem pontuação).
  • Treinamento: constrói um mapa "sequência de N palavras → próximas palavras possíveis".
  • Geração: caminha pelo mapa probabilisticamente usando Math.random().
  • Serialização: o mapa é convertido para JSON, depois para base64 com btoa().
  • Persistência: o base64 é salvo em localStorage["markov-ai-model"].
  • Questões: combina frases geradas pela Markov + templates estruturais + dados reais dos datasets.

Sobre este sistema

Este é um banco de questões educativo sobre os principais bancos de dados usados no treinamento de modelos de Inteligência Artificial. Ao contrário de sistemas baseados em IA, todas as buscas são feitas por código JavaScript puro, sem qualquer chamada para modelos de linguagem. Isso torna o sistema rápido, transparente, gratuito e ótimo para estudos.

Como funciona a busca (sem IA)

  • Busca textual: usa String.includes() e toLowerCase() para encontrar termos em qualquer campo do dataset.
  • Busca fuzzy: usa o algoritmo de distância de Levenshtein para encontrar termos parecidos (tolera erros de digitação).
  • Filtros: aplicam critérios exatos (categoria, modalidade, licença) usando Array.filter().
  • Ordenação: usa Array.sort() com comparadores personalizados.
  • Quiz: perguntas e respostas são geradas aleatoriamente com Math.random() e embaralhamento Fisher-Yates.

Dicas de uso

  • Na aba Explorar, combine busca textual com filtros para refinar resultados.
  • Use busca fuzzy quando não souber a grafia exata (ex: "laion" encontra "LAION-5B").
  • No Modo Estudo, use flashcards para memorizar características.
  • No Modo Quiz, teste seu conhecimento com perguntas geradas por código.
